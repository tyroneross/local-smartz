## 1. Governing Thought

Design agent skills with clear, keyword‑rich descriptions, externalized logic, and rigorous testing to ensure they trigger correctly, scale efficiently, and remain secure.

## 2. Key Practices


- **Trigger Precision**: Craft concise, scenario‑specific `description` fields that use action verbs and context cues.
- **Three‑Stage Loading**: Separate the main prompt, skill description, and external references to keep the context window lean.
- **External Knowledge & Scripts**: Store large data, templates, and deterministic scripts in external files; reference them in the skill.
- **Scope & Portability**: Choose workspace or user scope appropriately and avoid hard‑coded paths to ensure reusability across models and teams.
- **Security & Auditing**: Review for external URLs, credentials, and disable unused skills.
- **Testing & Iteration**: Build test cases, validate across models, and refine based on feedback.
- **Workflow Composition**: Combine multiple skills with conditional logic for complex processes.


## 3. Implementation Steps

1. Write a clear `description` with keywords.
2. Organize logic into `scripts/` and reference external assets.
3. Set `scope` (workspace or user) and document.
4. Audit for security risks.
5. Create test scenarios and run across models.
6. Iterate until stable.


## 4. Final Checklist

✅ Description is keyword‑rich and concise.
✅ Logic is externalized in scripts/assets.
✅ Scope is correctly set.
✅ Security audit completed.
